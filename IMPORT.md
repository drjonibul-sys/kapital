# Импорт в Капитал · Фокус 4.0

Выберите новый или существующий портфель, JSON/CSV и источник — файл или текст. Сначала выполняется проверка; подтверждение нужно после предпросмотра. Обычный импорт дополняет выбранный портфель. «Заменить все записи» доступно для полной резервной копии и подтверждается отдельно. Максимум — 12 МБ и 100 000 операций.

JSON: собственные резервные копии форматов 1/3/4/5; список операций; объект с `operations`/`операции`, включая пометку `invest-ops/1.0`; старые данные портфеля с `stocks`, `bonds`, `funds`, `cashDeposits`, списками `buys`/`purchases`, `sells`/`sales`, `dividends`, `coupons`, `redemptions`, `cashWithdrawals`, `conversions`, `fees`. Неизвестная структура отклоняется с объяснением, без частичной записи.

CSV: разделитель `,` или `;`, кавычки и удвоенные кавычки, переносы в кавычках, UTF-8 BOM, десятичная запятая. Даты: YYYY-MM-DD, DD.MM.YYYY, ISO timestamp (сохраняется указанная календарная дата). Дата операции обязательна; она не подменяется сегодняшней. Для CSV без type тип выбирается в форме. В JSON-списках type обязателен.

Основные столбцы:

| Тип | Поля |
|---|---|
| deposit / withdrawal / fee | date, amount, currency, note |
| buy / sell / bondBuy / bondSell | date, ticker, currency, quantity, price, commission, feeCurrency |
| dividend / coupon | date, ticker, amount (до налога), currency, taxAmount или taxRate |
| redemption | date, ticker, currency, quantity, price либо gross_amount |
| fx / conversion | date, fromCurrency, fromAmount, toCurrency, toAmount (либо rate) |

Дополнительно: assetType (`stock`, `bond`, `fund`), assetClass, external_id, nominal, couponAmount (за одну бумагу), couponDate, couponFrequency (1/3/6/12 месяцев), maturityDate. Поддерживаются русские заголовки и основные русские названия операций. Цена облигации вводится в деньгах за одну бумагу, а не в процентах номинала. `gross_amount` означает стоимость до комиссии; `net_amount` — денежную сумму после комиссии. Если известна точная общая сумма сделки, она имеет приоритет над округлённой ценой за бумагу.

Пример:

```csv
type;date;ticker;assetType;currency;amount;quantity;price;commission;note
deposit;2026-01-01;;;KZT;100000;;;;Пополнение
buy;2026-01-02;TEST.KZ;stock;KZT;;10;1000;10;Покупка
sell;2026-02-01;TEST.KZ;stock;KZT;;4;1100;5;Частичная продажа
```

Валюта сделки берётся из явного поля, затем из хронологической истории выбранного тикера в портфеле, затем из .US/.KZ, затем KZT. Отдельная валюта комиссии сохраняется. Налог уменьшает подтверждённое поступление; сбор при выплате создаёт отдельный расход.

Дубли определяются по external_id, а без него — по содержимому и числу одинаковых строк. Две одинаковые операции внутри одного файла сохраняются; повторная загрузка этого файла не добавляет их второй раз. Совпадающие тикеры объединяются с переназначением ссылок. Начальные остатки снимков также защищены от повторного сложения. Конфликтующие начальные остатки собственной копии требуют нового портфеля или полного восстановления.

Историю, начинающуюся раньше имеющегося снимка, импортируйте в новый портфель: иначе старые остатки будут учтены повторно. Дата погашения в instruments сама по себе не подтверждает поступление номинала. Отрицательные поступления, похожие на отмены, не превращаются в положительные выплаты: взаимно отменённые строки нужно согласовать до импорта.
