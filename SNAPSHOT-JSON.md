# Снимки портфеля (формат 4)

Импорт поддерживает JSON форматов 1, 3 и 4. Экспорт и локальное хранение используют формат 4. Прежние документы обновляются при чтении. Импорт полностью заменяет записи после проверки и подтверждения, с локальной копией предыдущего состояния.

Снимок — начальные остатки, без вымышленных покупок. У портфеля `snapshotDate` в формате YYYY-MM-DD. `initialMinor` задаёт базу результата с этой даты; историческую прибыль по такому снимку считать нельзя. Валюта всех денежных полей, кроме исходных сумм в `cashBreakdown`, — валюта портфеля. Денежные поля — целое число сотых единиц валюты; количества — целое число миллионных долей бумаги.

У начальной позиции `openingQuantityUnits`, `openingValueMinor` (оценка снимка, не историческая себестоимость). Количество позиции должно равняться начальному количеству плюс последующие покупки. `valuationMinor` сохраняет точную оценку всей позиции, независимо от округлённой справочной `priceMinor`. Диаграмма и итоги используют `valuationMinor`. Для перехода к оценке через цену пользователь явно подтверждает переоценку; до этого докупка такой позиции отключена с объяснением. Название и классификацию можно менять без потери точной оценки.

Необязательное `cashBreakdown`: исходные остатки `{currency,amountMinor,valueMinor}`. Их сумма `valueMinor` равна `cashMinor`. После изменения денег исходная разбивка удаляется, поскольку приложение не ведёт многовалютный денежный журнал.

Необязательное знаковое `valuationAdjustmentMinor` сохраняет явное расхождение строк и итога исходного документа. Итог = деньги + оценки позиций + корректировка. Диаграмма использует сумму положительных компонентов до корректировки и сообщает об этом. Корректировка не подменяет значения отдельных активов.

`brokerData` у актива и `report` верхнего уровня могут сохранять исходные котировки, ISIN, страницы источника и пояснения. Они не участвуют в расчёте и не отправляются на сервер. Отчёты клиентов и заполненные финансовые JSON не включаются в исходники, сборку, тестовые примеры и ZIP сайта.
