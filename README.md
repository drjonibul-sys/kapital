# Капитал · Фокус 4.1.0

Учёт портфелей в Firefox на телефоне. Светлый и ночной «Сапфир», хранение в браузере, без синхронизации, уведомлений, внешних котировок и объединения валют.

Приложение: https://drjonibul-sys.github.io/kapital/

Прежний адрес https://kapital-focus-phone.magicgleam66.chatgpt.site из этого репозитория не обновляется. Записи между адресами сами не переносятся: экспортируйте JSON по старому адресу и импортируйте по новому.

В версии 4.0.1 итог портфеля показан через «/», например `555$/1 754тг`. В обзоре и разделе «Наличные» остатки перечислены по применяемым валютам: `$ 452`, `тг 4 455`. Валюты не пересчитываются и не складываются между собой.

## Работа на телефоне

Откройте постоянную ссылку в обычной вкладке Firefox и добавьте её в закладки. После первого открытия подготавливается офлайн-копия. Данные прежней версии читаются автоматически; при первом сохранении формата 5 сохраняется исходная копия. Её экспорт: «Настройки → Копия до обновления формата».

ZIP содержит самостоятельный `dist/Kapital.html`: код, стили и диаграммы встроены, внешние библиотеки не нужны. На реальном iPhone открытие локального HTML из «Файлов» в этой проверке не выполнялось. Основной проверяемый способ работы — постоянная ссылка и офлайн-кэш. Не очищайте данные сайта без JSON-копии; данные разных браузеров и адресов сайта не общие.

## Обновление приложения (4.1.0)

«Настройки → Приложение» показывает текущую версию и содержит кнопку «Обновить». Обновление заменяет только файлы приложения: портфели, операции и настройки остаются в браузере. Перед первым запуском новой версии сохраняется копия данных («Резервные копии → Копия до обновления приложения»). Отложенная новая версия включается после полного закрытия приложения.

Выпуск новой версии: увеличить `version` в `package.json`, выполнить `node scripts/build.mjs` и `node --test`, разместить содержимое `dist` в корне ветки `gh-pages` (файл `.nojekyll` оставить). GitHub Pages публикует эту ветку автоматически; изменения только в `main` сайт не обновляют. Смена адреса сайта не переносит данные — перед ней экспортируйте JSON.

## Изменения версии 4.0

- Несколько портфелей и переименование с главной плитки. KZT по умолчанию; итоги отдельно для KZT/USD/RUB, GBP показывается при наличии соответствующей истории.
- Акции, облигации и фонды, классы, круговая диаграмма, ручная оценка.
- Единый журнал пополнений, выводов, покупок, продаж, дивидендов, купонов, погашений, комиссий и обменов. Редактирование и удаление с пересчётом.
- Скользящая средневзвешенная себестоимость, дробные количества, комиссии в своей валюте, налог с выплат, ручная замена результата продажи и сброс к автоматическому.
- Справочник эмитентов: номинал, купоны, периодичность, даты. Автоподстановка, ожидаемые выплаты и купонная доходность по годам владения. Наличные меняются только по подтверждённым поступлениям.
- Активные инструменты и история. Удаление плитки сохраняет операции; полное удаление подтверждается отдельно. Короткий/полный свайп, кнопка удаления 70×70.
- График капитала и реализованного дохода; процент к пиковому вложенному капиталу. Текущая оценка открытых позиций показана отдельно.
- JSON/CSV: новый/существующий портфель, предпросмотр, добавление без дублей, отдельное полное восстановление и копия до импорта.

Расчёты: [ACCOUNTING.md](ACCOUNTING.md). Импорт: [IMPORT.md](IMPORT.md). Старый формат снимков: [SNAPSHOT-JSON.md](SNAPSHOT-JSON.md). Журнал требований и уточнений: [changelog.txt](changelog.txt), без приватных финансовых примеров исходного файла.

## Сборка

Требуется Node.js; внешних зависимостей нет.

```text
node scripts/build.mjs
node --test
node scripts/preview.mjs
```

Локальная проверка: http://127.0.0.1:47833; порт настраивается переменной PORT. Интерфейс: `src/ui.js`; учёт: `src/ledger.mjs`; импорт: `src/ledger-import.mjs`. `portfolio.mjs` сохранён для точной арифметики и чтения прежних копий. Имя IndexedDB не менялось.

## Проверено

69 автоматических проверок (в 4.0 — 64): арифметика, частичные продажи, комиссии, налоги, купоны, погашения, даты, архив, миграция, импорт/дубли, самостоятельный HTML и темы. Синтетический импорт 500 операций и его повторная загрузка сохраняют баланс и не удваивают историю.

В браузере на размере 390×844 проверены портфель/переименование, дробная покупка, продажа/правка/ручной результат, контроль остатка, дивиденды/налог, справочник облигаций, купон/погашение, архив/возврат, короткий/полный Pointer Events свайп, кнопка 70×70, обмен, график по валютам, CSV/дубли, сохранение после открытия. Отдельно проверено обновление с HTML 3.3, первая запись формата 5 и экспорт исходной копии формата 4. Существующий локальный снимок прошёл проверку количеств, точных оценок и исходных валютных остатков без создания покупок.

Реальный iPhone/iOS/Firefox и полный оригинальный файл операций другого приложения, упомянутый в исходном журнале, за проверенные не выдаются.
